## 1. Project Overview
This project is for the redesign of the BMW Pretoria dealership website. The goal is to create a modern, user-friendly website that allows customers to view BMW models, book test drives, and contact the dealership easily.

## 2. Project Goals
- Increase online test drive bookings by 30%
- Showcase all BMW models with high quality images
- Improve mobile user experience
- Provide clear contact and location information

## 3. Target Audience
Primary: BMW customers in Pretoria, Gauteng aged 25-55 looking to buy or test drive a BMW.

## 4. Key Features and Functionality
- Home page with featured models
- About page with dealership history
- Products page to view BMW models
- Enquiry page to book a test drive
- Contact page with map and details
- Responsive design for mobile and desktop

## 5. Technical Requirements
- HTML5, CSS3
- Hosted on shared hosting
- Domain: www.bmwpretoria.co.za
- No frameworks for Part 1
